# Research

Dated notes that carry evidence: handoffs to other agents and their
reports, experiment write-ups, and requirements gathered from another
project. An RFD cites a note here when it needs the evidence. The note is
not authoritative; the RFD is.

- One note per file, named `YYYY-MM-DD-slug.md`, dated the day it was
  written.
- A note is kept as written. Later information is a new note, or a dated
  addition at the end of the old one, marked as arriving after it.
- A number an RFD quotes from a note must be re-derivable: the note says
  what was run, with which toolchain, and where the code is.
- The book carries every note under Research, through an include from
  `src/research/`, so a link from an RFD to a note is checked.

An idea that has no evidence yet goes in [`notes/`](../notes/README.md).
